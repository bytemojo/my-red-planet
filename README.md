# My Red Planet

Stardew-style Mars colony game for the NASA Space Apps Challenge. Survive Mars. Discover Mars. Make Mars yours.

```
npm install
npm run dev      # play
npm run check    # tests + type-check + build
```
AI agents: read **AGENTS.md** first, then **HANDOFF.md**. Controls: WASD/arrows to move, E to act, M for the menu.
